# Community guidelines / 社区行为准则

My Mail welcomes contributors of different backgrounds, experience levels and
languages. Discuss the work with respect; focus criticism on ideas and behavior,
not a person's identity or ability.

Expected behavior includes giving useful context, acknowledging corrections,
respecting privacy and accepting that maintainers may decline a change.
Harassment, threats, discriminatory remarks, sexual content, doxxing, spam and
publication of someone else's private mail or credentials are not acceptable.

These guidelines apply to project issues, pull requests, discussions and other
spaces maintained by this project. Maintainers may edit/remove harmful content,
limit participation or block accounts. They should explain moderation decisions
where doing so does not expose private information or create further harm.

For a conduct concern, use a contact method offered on the
[maintainer's GitHub profile](https://github.com/yinxianwei). If no private contact
method is available, request one in an issue without identifying affected people
or posting sensitive details. Security vulnerabilities use [SECURITY.md](SECURITY.md).
This volunteer project cannot guarantee response times or confidentiality on a
public GitHub thread.

中文：尊重不同背景与经验的参与者，就事论事，不发布骚扰、歧视、威胁、垃圾信息或他人的私人资料。维护者可以移除有害内容或限制参与。需要私下处理的行为问题，请先通过维护者主页提供的方式联系；公开请求联系方式时不要附带私人信息。
