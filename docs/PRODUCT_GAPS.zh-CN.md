# 产品功能盘点

日期：2026-11-08。依据当前源码与本地测试整理，服务商和其他平台的实际表现仍需分别验收。

## 本轮补齐

| 功能 | 当前行为 |
| --- | --- |
| 英中邮件翻译（试验性） | macOS 15+ 苹果系统翻译，原文保留、可取消和重试；需要系统英中语言包，不依赖云端 API Key |
| 附件预览与下载 | 图片、PDF 分页与文本预览；文件名可下载，支持缓存离线；其他格式保留下载入口 |
| 英文界面 | 设置中选择跟随系统、简体中文或 English；菜单栏、通知、附件面板同步切换，邮件原文保持不变 |
| 本地草稿入口 | 侧栏“本地草稿”汇总已添加账号的非空本机草稿，展示所属邮箱、主题、收件人与附件数量 |
| 继续编辑 | 回到草稿所属邮箱，恢复原草稿槽位、正文、引用、抄送/密送和附件路径 |
| 删除本地草稿 | 先确认再删除；失败保留草稿，支持重试；不删除服务器草稿或原附件文件 |
| 邮件筛选 | 全部、未读、星标、附件可与关键词组合；切换文件夹/账号时重置 |
| 搜索边界 | 搜索当前列表的已缓存主题、发件人、收件人和附件名；不声称是正文全文搜索 |

筛选时不自动遍历服务器的全部历史邮件；需要更多范围时，先在“全部”视图加载更早邮件。附件筛选依赖已经读取并缓存的附件信息，未读取正文的邮件可能还没有附件元数据。本地草稿独立于服务器的“草稿”文件夹。

## 建议下一批：完善日常使用闭环

| 优先级 | 缺口 | 完成标准 |
| --- | --- | --- |
| P1 | 账号编辑与重新认证 | 修改服务器配置、重新测试并更新授权码；失败时保留原可用配置 |
| P1 | 账号移除/暂停 | 明确区分停止检查、移除本机缓存和删除凭证；确认中说明未发草稿的处理，不能误删服务器邮件 |
| P1 | 批量邮件管理 | 多选已读/未读、星标、移动与删除；复用现有离线队列，危险操作确认，部分失败可识别 |
| P1 | 多封新邮件独立草稿 | 当前回复/转发按邮件分槽，新邮件每账号仍共用 `new` 槽；需要为每封新邮件分配独立标识，避免继续写另一封时覆盖 |
| P1 | 待同步操作详情 | 现有待同步计数之外，展示受影响邮件、失败原因和重试/取消入口；不把 SMTP 未确认邮件纳入自动重发 |
| P1 | 本地正文全文搜索 | Go/SQLite 侧建立索引，返回范围和结果数量；区分未缓存正文与未匹配，不依赖浏览器持久化邮件 |
| P2 | OAuth2 | 支持要求 OAuth 的账号；令牌保存在系统凭证库，明确授权范围和撤销方式 |
| P2 | 服务器草稿同步 | 本地保存与 IMAP 草稿之间有明确关联，处理并发编辑和冲突，避免覆盖或重复生成 |
| P2 | 扩展附件预览 | Office、压缩包等格式尚未预览；增加更多格式时继续限制资源，禁止执行附件 |
| P2 | 快捷键统一与无障碍 | 菜单/快捷键文案一致，焦点与键盘路径完整 |
| P2 | 签名、公证与自动更新 | 分发身份可信、更新包有签名、失败可恢复；当前预览包不能视为已公证 |

## 已有实现，尚需真实验收

- 服务商矩阵：认证、收发、中文编码、抄送/密送、附件、文件夹管理与 IDLE 通知，分别记录通过/失败。
- 断网、睡眠唤醒、换网、8 小时运行与其他客户端同时修改邮件。
- 大邮箱的分页、列表性能、缓存淘汰与完整进程组内存；不提前承诺测量结果。
- Windows、Linux、Intel Mac 和旧版系统 WebView；目前的本机检查不能代替平台验收。

后续顺序建议：账号维护 → 批量管理与待同步详情 → 全文搜索 → OAuth/平台扩展。更新方向同步到[路线图](ROADMAP.md)，本轮不处理已发送加载问题。
